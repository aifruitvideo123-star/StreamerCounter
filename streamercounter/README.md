# StreamerCounter

Fabric client mod for Minecraft 1.21.11.

## Build on GitHub

1. Upload the contents of this folder to the root of your GitHub repository.
2. Open the **Actions** tab.
3. Select **Build StreamerCounter** and run the workflow (or push a commit).
4. Open the completed workflow run and download the **StreamerCounter-JAR** artifact.

The mod uses Java 21 and Yarn mappings because the supplied Java source uses Yarn names.
